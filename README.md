# Giddem_Generosity
Our biggest-scale project to date.
This project is our submission for the 3rd semester final project assignments in Game Design and Unity Development courses at Mentor College.

Game inputs:
WASD -> Movement
LMouse -> Attack (both hold and tap)
E -> Interact (pickup, npc)
RMouse -> Ability interact (grapple, telekinesis)
Space -> Dash
